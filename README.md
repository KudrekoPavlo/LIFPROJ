#Overtake - Jeu de course sur Unreal Engine 5.7.2

##  Description du projet

Jeu de course avec support multijoueur, créé sur Unreal Engine 5. Les joueurs peuvent créer des serveurs, compétitionner sur différentes pistes contre les autres joueurs ou l'IA.

## Fonctionnalités

-  Jeu en réseau (jusqu'à 10 joueurs)
-  Plusieurs circuits (Las Vegas, Shanghai, Montréal...)
-  Personnalisation
-  Système d'affichage de resultat et anti triche

##  Configuration système requise

| Composant | Minimum | Recommandé |
|-----------|---------|-------------|
| **OS** | Windows 10 | Windows 11 |
| **Processeur** | 1.5 - 2 GHz|
| **RAM** | 8 Go | 16 Go |
| **Carte graphique** | 2-4 GO |
| **DirectX** | Version 11 | Version 12 |
| **Espace disque** | 10 Go | 20 Go |

##  Commandes

| Action | Touche |
|--------|--------|
| Accélérer | W ou ↑ |
| Freiner | S ou ↓ ou Space|
| Tourner à gauche | A ou ← |
| Tourner à droite | D ou → |
| Allumer les phares | L |
| Menu | Esc |

1. Téléchargez la dernière version depuis : https://drive.google.com/drive/folders/1ywXQlrAc3k88Czrq3RaIPoVrwULOg0vA?usp=drive_link (google drive car contient des fichiers de grosse taille insupportable par git)
